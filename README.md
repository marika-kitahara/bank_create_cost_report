# 後方数値分析ツール メルマガ 新型 定例用 生成 — 引き継ぎ用説明書

## 1. アプリ概要
メール広告レポート・媒体コード・後方数値ローデータを、既存のExcelテンプレートに反映し、後方数値分析用のExcelを生成するStreamlitアプリです。ファイル1（テンプレート）は必須で、ファイル2〜4は任意です。未指定の対象シートは原則としてテンプレートの内容を維持します。

## 2. 操作方法
1. 「ファイル1：後方数値分析ツール メルマガ 新型 定例用」にExcel（.xlsx）をアップロードします（必須）。
2. 更新したいデータに応じて、ファイル2（メール広告レポート）、ファイル3（媒体コード、複数選択可）、ファイル4（後方数値ローデータ）をアップロードします。
3. 「Excelを生成」を押し、進捗と完了メッセージを確認します。
4. 「生成Excelをダウンロード」から「後方数値分析ツール_生成.xlsx」を保存します。
5. 「汎用式を使用した行」の警告が出た場合は、出力した媒体コードマスタのD:G列・I列を確認してください。

## 3. 入力ファイルと必要な構成
【ファイル1：テンプレート／必須】
・Excel .xlsx。出力に残すシートは「コストデータ」「後方数値データ(加工版)」「媒体コードマスタver3」の3つです。処理にはこれらのシートが必要です。
・「コストデータ」はB列の媒体名、C列・D列の区分、E列の年齢、およびF列以降の月別集計欄を使用します。
・「媒体コードマスタver3」はB列の媒体コードを照合キーとして使用します。
・「後方数値データ(加工版)」はA:AD列の既存ヘッダーをファイル4との照合に使います。

【ファイル2：メール広告レポート／任意】
・Excel .xlsx。テンプレートのコストデータB列の媒体名をもとに、名称が対応するシートを検索します。「Yahoo!ダイレクトオファー」は「YDO」として検索します。
・レポートシートの先頭20行以内から「配信日」「セグメント別」「Cost(Gross)」を含むヘッダー行を検出します。
・配信年月、セグメント、Grossコストを集計して「コストデータ」に反映します。

【ファイル3：媒体コード／任意・複数可】
・Excel .xlsx。各ファイルの先頭シート、2行目以降のA:G列を読み込みます。
・入力A/B/C列→出力マスタA/B/C列、入力D列→出力H列、入力E/F/G列→出力J/K/L列に配置します。
・出力D/E/F/G/I列は、媒体コード（B列）がテンプレートに存在すれば既存の値・式を転記し、式の参照行を調整します。
・新規媒体コードの場合はD/E/I列に汎用式を設定し、F/G列は空欄です。要確認です。

【ファイル4：後方数値ローデータ／任意】
・Excel .xlsx。先頭シートのA:AD列を読み込みます。
・A:AD列のヘッダーがテンプレートの「後方数値データ(加工版)」と一致しない場合はエラーになります。
・入力のB列を日付、C列を媒体コード、L列を年齢として参照します。

## 4. 主な集計・転記ルール
【コストデータ】
・ファイル2の配信日から「YYYY/MM」の月を抽出し、テンプレートのF列以降に月別コストを設定します。
・通常媒体はセグメント名等を正規化して部分一致で集計します。「Total」「合計」は通常のセグメント指定時に除外します。
・Yahoo!ダイレクトオファー（YDO）は、親セグメントと「20〜」「30〜」等の年齢十歳刻みの区分を用いて集計します。
・媒体に対応するレポートシートが見つからない場合、その媒体行の値は更新されません。対象月の列自体は更新されます。

【媒体コードマスタver3】
・アップロードした媒体コードデータで行を再構成します。
・既存媒体コードの数式はopenpyxlのTranslatorで新しい行へ移動します。
・新規コードの汎用式はTEXTAFTER/TEXTBEFOREを使います。利用するExcelの関数対応状況にも注意してください。

【後方数値データ(加工版)】
・ファイル4を指定すると既存のデータ行を置き換えます。
・A:AD列は元データ、AE:AI列には「媒体」「コスト」「年齢グループ」「申込月」「YDO行数判定」を追加します（合計35列）。
・媒体は媒体コードマスタのB列をキーに、L列（空ならC列を分割）から取得します。
・コストは「コストデータ」の媒体×月の合計額を、同じ媒体×月に該当する後方数値の行数で均等配分します。
・年齢グループは10歳刻み、申込月はYYYY/MMです。
・注意：この実装のコスト配分は媒体×月単位です。セグメント別・年齢別の配分ではありません。

## 5. 出力Excelの仕様
・ファイル名：「後方数値分析ツール_生成.xlsx」
・保持するシート：「コストデータ」「後方数値データ(加工版)」「媒体コードマスタver3」のみ。テンプレート内のその他のシートは削除されます。
・フォントの基本設定をMeiryo UIへ変更し、フィルターを解除、表示位置をA1へ設定、過度に広い列幅を調整します。
・数式をExcelで再計算する設定を行います。Python上で数式の計算結果を評価するものではありません。

## 6. 必要なライブラリ
requirements.txtに記載する主な外部ライブラリ：
・streamlit
・openpyxl

標準ライブラリ：io、re、copy、time、collections、datetime、zipfile。

## 7. 主な関数と保守箇所
・generate()：全処理の実行順序、任意ファイルの分岐、出力管理。
・build_cost_sheet()：メール広告レポートからの月次コスト集計。
・parse_report_sheet_aggregated()：レポートのヘッダー検出とセグメント別集計。
・build_master_sheet()：媒体コードマスタの再構築と数式転記。
・build_backend_sheet()：後方数値ローデータの取り込み、媒体・月別のコスト配分。
・derive_master_media()：媒体コードから媒体名への対応付け。
・month_key()：日付をYYYY/MMへ正規化。
・compact()：照合用の文字列正規化。
・KEEP_SHEETS：出力に残すシートの一覧。
・save_fast()：ExcelのZIP圧縮保存処理。

## 8. 制約・注意事項
・ファイル2〜4が任意でも、ファイル1の必須シートが欠けている場合は処理できません。
・ファイル2のレポートシート名・ヘッダー名が想定と違う場合、対象データが取り込まれない可能性があります。
・ファイル3の新規媒体コードはF/G列の式を自動生成しません。出力後の確認が必要です。
・ファイル4のA:AD列ヘッダーは完全一致（前後空白等の正規化後）が必要です。
・媒体名の表記ゆれがあると媒体×月のコストが一致せず、配分額が0になる場合があります。
・ファイル4の読み込みにより、テンプレートの後方数値データ行は置換されます。元のテンプレートは別途保管してください。
・処理中は一部でopenpyxlの内部属性（_cells、_current_row、_fonts）を使用しているため、ライブラリ更新時は動作確認を行ってください。
・複数ファイルの入力順序や媒体コードの重複がある場合、後から読んだ値で媒体名対応が上書きされることがあります。

## 9. 引き継ぎ時の動作確認
1. テンプレートのみで生成し、3シートが保持されることを確認。
2. ファイル2を加え、月見出し・通常媒体・YDOのコスト集計を確認。
3. ファイル3を加え、既存媒体コードの数式転記と新規コードの警告を確認。
4. ファイル4を加え、A:AD列の取り込み、AE:AI列の値、媒体×月の均等配分を確認。
5. 生成したExcelを実際に開き、数式の再計算と表示崩れがないか確認。
6. GitHubリポジトリ・Streamlit公開先・入力テンプレートの保管場所を引き継ぎ担当者に共有。
